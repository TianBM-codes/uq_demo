# 不确定性传播演示程序 (UQ Demo)

基于 PyQt6 的交互式演示程序，用于展示不确定性在**跨阶段**和**跨层级**两种场景下的传播规律。

## 功能特性

### 1. 跨阶段流程
- 模拟产品全生命周期：设计 → 制造 → 装配 → 服役
- 每个阶段引入独立的不确定性偏差
- 方差线性叠加：σ_out² = σ_in² + σ_stage²
- 直观展示不确定性如何随阶段累积放大

### 2. 跨层级流程
- 模拟系统层级结构：材料层 → 部件层 → 子系统层 → 系统层
- 层级间存在放大效应（级联放大）
- 支持双击容器节点进入子层级
- 面包屑导航，可返回上层

### 3. 交互功能
- 节点参数可实时编辑（均值、标准差、放大系数）
- 点击运行按钮，带动画展示传播过程
- 节点高亮 + 连线粒子流动效果
- 右侧面板实时显示输出统计量

## 项目结构

```
uq_demo/
├── main.py              # 程序入口
├── core/                # 核心计算层（可直接移植到 UQSim）
│   ├── distribution.py      # 分布定义
│   └── uncertainty.py       # 不确定性传播算法
├── canvas/              # 画布渲染层（接口对齐 UQSim）
│   ├── base_node.py         # 节点基类 + 端口
│   ├── connection.py        # 贝塞尔连线 + 流动动画
│   ├── graphics_view.py     # 画布视图（缩放/平移/网格）
│   ├── stage_node.py        # 跨阶段节点
│   └── container_node.py    # 跨层级容器节点
└── ui/                  # Demo 外壳层（集成到 UQSim 时替换）
    ├── main_window.py       # 主窗口
    ├── toolbox_panel.py     # 左侧工具箱
    └── property_panel.py    # 右侧属性面板
```

## 移植说明

### 向 UQSim 集成的步骤

1. **core/ 目录**：直接复制，纯计算无依赖
2. **canvas/ 目录**：
   - `base_node.py` 继承关系对齐 UQSim 的 NodeBase
   - `connection.py` 连线类可直接复用
   - `graphics_view.py` 替换为 UQSim 已有画布
   - `stage_node.py` / `container_node.py` 作为新节点类型注册
3. **ui/ 目录**：不需要，直接用 UQSim 主窗口，节点通过工具箱添加

## 运行方式

```bash
pip install PyQt6
python main.py
```

## 操作说明

- **切换模式**：左侧工具箱选择"跨阶段流程"或"跨层级流程"
- **加载模板**：点击"加载默认模板"自动生成演示流程
- **编辑参数**：单击选中节点，右侧面板修改参数
- **运行传播**：点击工具栏"▶ 运行"或右侧"运行传播"按钮
- **进入子层级**：双击容器节点
- **返回上层**：点击工具栏"← 返回上层"
- **缩放画布**：Ctrl + 鼠标滚轮
- **平移画布**：Shift + 拖拽 或 鼠标中键拖拽

## 计算原理

### 跨阶段（串联叠加）
```
σ_total² = σ₁² + σ₂² + σ₃² + ... + σₙ²
```
各阶段不确定性独立，方差直接相加。

### 跨层级（级联放大）
```
σ_layer_out = √[(σ_layer_in × amplification)² + σ_self²]
```
上层输入经过放大系数放大后，与本层自身偏差叠加。
